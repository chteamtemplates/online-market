Trendora v1.0

A premium fashion e-commerce template — built with pure HTML, CSS & Vanilla JS. No framework. No build step. No dependencies.

Welcome! This document walks you through everything you need to set up, customize, and ship Trendora as your own store. Read it once end-to-end (it's short) — you'll be productive in under 30 minutes.

TL;DR: Unzip the folder. Open index.html in a browser. You're live. To customize, edit style.css (look) and store.js (products, cart, promos).

Installation

Trendora is a static site. There is nothing to install, build, or compile.

Option A — Open directly

Just double-click index.html. Works in Chrome, Firefox, Safari, Edge.

Option B — Local server (recommended for development)

cd trendora/
python3 -m http.server 8000
# then open http://localhost:8000

Or with Node:

npx serve .

Brand & colors

All colors live as CSS custom properties at the top of style.css. Change one value, the whole site updates.

:root {
  --color-bg: #fbfaf7;
  --color-text: #1a1a1a;
  --color-accent: #c9a961;   /* ← brand color, change this */
  --color-success: #2d7a4a;
  --color-danger:  #c53030;
  /* ... */
}

Typography

Trendora uses two Google Fonts loaded via <link> in each HTML head:

  • Playfair Display — display / headings
  • Inter — body / UI

To swap fonts, edit the <link> tag in each HTML page and update these CSS variables:

:root {
  --font-display: "Playfair Display", Georgia, serif;
  --font-body:    "Inter", system-ui, sans-serif;
}

Adding / editing products

All products are defined as a JS array near the top of store.js:

const PRODUCTS = [
  {
    id: 1,
    name: 'Classic Beige Trench Coat',
    brand: 'Trendora Classic',
    price: 189.00,
    oldPrice: null,           // null if not on sale
    category: 'Women',         // Women | Men | Shoes | Accessories
    badge: 'New',              // New | Sale | Best Seller | null
    color: '#c9b894',
    rating: 4.8,
    reviews: 124,
    stock: 12,
    image: 'https://...',
    gallery: ['https://...', 'https://...'],
    desc: 'Long-form description of the product…',
  },
  // ... add more
];
Tip: All product images use Unsplash placeholders. Replace them with your own product photos before launch — Unsplash images aren't licensed for use as commercial product imagery.

Promo codes

Defined in store.js:

const PROMO_CODES = {
  TRENDORA10: { type: 'percent',  value: 0.10, label: '10% off your order' },
  SUMMER25:   { type: 'percent',  value: 0.25, label: '25% off summer collection' },
  FREESHIP:   { type: 'shipping', value: 0,    label: 'Free shipping' },
};

To add a new code:

PROMO_CODES.WELCOME20 = {
  type: 'percent',          // 'percent' | 'fixed' | 'shipping'
  value: 0.20,              // 0.20 = 20%, or 25 = $25 fixed
  label: '20% welcome discount'
};

Shipping rule

By default, shipping is $15 flat, free over $100. To change, edit store.js:

const SHIPPING_FLAT = 15;
const FREE_SHIPPING_THRESHOLD = 100;

Connecting a backend

Trendora ships as a frontend template. The cart, wishlist, and orders are stored in the browser via localStorage. To make orders actually persist server-side, you have two main paths:

  1. Use a hosted commerce backend (Shopify, Snipcart, Foxy, Lemon Squeezy, Paddle) — recommended.
  2. Build your own backend and replace the localStorage calls with fetch calls.

Stripe Checkout (easiest)

For each product, create a Stripe Payment Link in your dashboard. Then in checkout.html's submit handler, redirect to the link instead of showing the local success view:

// Replace the success view with a Stripe redirect
window.location.href = 'https://buy.stripe.com/your-payment-link';

Shopify Storefront API

To use your existing Shopify catalog, replace PRODUCTS with a fetch call to Shopify's Storefront API. Documentation: shopify.dev/docs/api/storefront.

const res = await fetch('https://YOUR_STORE.myshopify.com/api/2024-04/graphql.json', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', 'X-Shopify-Storefront-Access-Token': 'YOUR_TOKEN' },
  body: JSON.stringify({ query: '{ products(first: 50) { edges { node { id title handle priceRange { minVariantPrice { amount } } } } } }' }),
});

Deployment options

Because Trendora is a static site, you can host it for free on:

  • GitHub Pages — push to a repo, enable Pages in Settings. Free.
  • Netlify — drag & drop the folder onto netlify.com/drop. Free + auto HTTPS.
  • Vercel — vercel deploy. Free + auto HTTPS.
  • Cloudflare Pages — connect your GitHub repo. Free + global CDN.
  • S3 + CloudFront — for AWS users.
  • Any shared hosting (cPanel, Plesk) — upload the files via FTP.

  • PATCH (e.g., 1.0.0 → 1.0.1): bug fixes

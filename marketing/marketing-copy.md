Trendora is a **fully-functional, conversion-optimized fashion store template** built with pure **HTML5, CSS3, and Vanilla JavaScript**. No React. No Vue. No build pipeline. No `npm install`. Just download, open `index.html`, and you're live.

### Why buyers choose Trendora

- **Zero-dependency**: pure HTML / CSS / Vanilla JS. No frameworks, no bundlers, no `npm`. Works on any web host (Apache, Nginx, GitHub Pages, Netlify, S3, Cloudflare Pages, your shared hosting).
- **Real working features** (not just static mockups):
  - Live product filtering by category / price / color / sale
  - Live search with instant results
  - Sliding cart drawer with quantity controls and live totals
  - Wishlist with localStorage persistence (survives page reload)
  - Multi-step checkout with full form validation
  - Promo code engine with 3 promo types: percent off, fixed off, free shipping
  - Order success screen with auto-generated order ID
- **Full design system** — every color, font size, spacing, and shadow is a CSS custom property in `style.css`. Change one variable, the whole site updates.
- **Mobile-first responsive** — looks great on every screen from 320px phones to 4K monitors.
- **RTL ready** — works perfectly with Arabic, Hebrew, Persian, Urdu (just add `dir="rtl"` to `<html>`).
- **SEO ready** out of the box — semantic HTML, Open Graph tags, JSON-LD structured data, `sitemap.xml`, `robots.txt`, optimized meta tags on every page.
- **Accessibility-conscious** — proper ARIA labels, keyboard navigation, semantic landmarks, focus states.
- **Beautifully commented code** — `style.css` is 1,500+ lines fully formatted and commented; `store.js` is 850+ lines with inline documentation. Easy for any developer to customize.
- **Free updates for 1 year** included with every purchase.

### Easy to customize

Want to change brand color from gold to red? Edit one line in `style.css`:

```css
--color-accent: #c9a961;  /* change to your brand color */
```

Want to add a product? Append one object to the `PRODUCTS` array in `store.js`. Done.

Want to add a promo code? Add one entry to `PROMO_CODES` in `store.js`:

```javascript
PROMO_CODES.MYCODE = { type: 'percent', value: 0.20, label: '20% off your order' };
```
